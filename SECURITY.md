# Security

Do not report exploitable vulnerabilities in public issues. Contact the maintainers privately through the repository security advisory feature. Never commit credentials. Treat all client messages as untrusted.

Milestone 2 adds password-based accounts, hashed passwords, server-side sessions in HttpOnly SameSite cookies, match membership checks on WebSocket connections, and ownership checks on every move. Each socket receives only its own match's state. The current match has no fog of war, so both participants see both scouts.

This is still a local development build. It has no login rate limiting, email recovery, HTTPS termination, production session controls, or deployment hardening. Do not expose it to the public Internet yet. Use separate browser profiles when testing two accounts on one computer; tabs in the same profile share the login cookie.
